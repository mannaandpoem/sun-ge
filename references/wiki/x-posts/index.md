# X 原帖语料库

这组材料是孙宇晨公开行为模型的第一人称社交媒体底座。它不把热度当真实性，也不把帖子当成交割证明；它保存本人当时选择公开什么、如何措辞、对谁说、用什么事件制造分发。

## 覆盖结果

- 语言：中文 **34**，英文 **66**。中文账号 2020 年才建立，且其公开精选时间线在 2021–2023 留存稀疏，因此没有伪造“中英各半”；2024 年后主动提高中文样本权重。
- 时间：从英文账号 2017 年启用开始；2018–2026 每年不少于 10 条。
- 账号：`@justinsuntron` 与 `@sunyuchentron`。转帖、第三方复述和被盗账号内容不计入本人原帖样本。

## 摄取方法

1. 读取 X 对两个本人账号公开返回的“best highlights”记录，保留 post ID、时间、正文、语言和互动字段。该集合是平台精选，不是随机样本。
2. 对平台精选覆盖不足的 2017、2018、2020、2023、2026，用公开报道、Telegram 公开转发页和 X 搜索结果发现原帖 ID，再从 X 的 `TweetResultByRestId` 公开响应回读原帖。发现页只负责找到 ID，不承担正文证据。
3. 逐年做主题与月份分散：协议/产品、交易/资本、传播/事件、治理/危机、关系/身份、AI/智能体、日常表达。
4. 短帖在长度允许时保存全文；长帖保存短摘和内容摘要，并标为 `Partial`。做逐字风格复现时必须回到原帖链接核对完整上下文、配图、引用帖与编辑状态。全部日期统一按 UTC 记录。

## 调用方式

- **解释**：可用帖子解释其公开叙事、注意力选择与受众切换。
- **归因**：只能写“孙宇晨在该帖中表示/宣布/提议”；交易完成、网络指标、法律结论需另找正式来源。
- **新表达**：先加载目标年份，再加载 `behavior/communication-style.md` 与相关事件材料；早期用早期语言，后期用后期语言。
- **危机**：帖子是当事人说法；必须同时读取 `wiki/controversies.md` 和正式文件。

## 已知空缺

2017 年现存可核验原帖少于后续年份，因此本库保留 3 条高价值早期样本。中文账号在 2020 年建立，但公开精选接口没有返回 2020 年原帖；这一段没有本人中文原文。互动数字会变化。
