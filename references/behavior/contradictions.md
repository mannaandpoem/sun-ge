# 矛盾张力

证据编号来自 [真实语料库](references/wiki/source-corpus.md)。

矛盾不必被强行消解；它们来自角色、周期和约束变化。分析任务是解释哪一端在什么条件下占优，而不是给人物贴“虚伪”或“善变”标签。

| 张力 | 两端 |
|---|---|
| 去中心化 vs 关键人影响 | 协议叙事强调去中心化，个人品牌仍高度可见 |
| 长期基础设施 vs 短期热点 | 网络建设需要多年，传播常追逐即时窗口 |
| 全球化 vs 地域监管 | 跨市场扩张与不同法律要求相冲突 |
| 高确定性表达 vs 高不确定行业 | 传播需要清晰，技术/市场/法律结果本质不确定 |
| 个人信用 vs 机构治理 | 创始人能快速动员，也会弱化独立制度信用 |
| 风险承担 vs 风险转移 | 高风险动作由本人承担一部分，也会外溢给用户、平台或生态 |
| 规则颠覆 vs 规则合法性 | S02/S06 崇尚规则未定期，S15 使用多边规则与可预测性语言 |
| 言论自由 vs 法律施压 | S08 自称支持言论自由，同时被追问针对媒体的律师函 |
| 无限行动力 vs 学会拒绝 | S06 强调早、快、持续；S03 长文把第一次“让我想想”写成核心转折 |
| 标注虚构 vs 自称属实 | S03 文末写“本文纯属虚构”，S41 中他次日称“绝大多数……符合我意愿的一个真实的陈述”；两句都是他本人说的，真假争论由此维持 |
| AI 冷静 vs 人类责任 | S04 把 AI 当建议系统，S03 把 AI 写成无犹豫决策者；现实后果仍由人承担 |
| “100% 听 AI” vs 人类否决 | S41 同时自述极高 AI 信任与首次不采纳 Claude，并把诉讼交给律师；口号不是固定授权规则 |
| AI 自动化规模 vs 控制透明度 | S41 称 AI 参与百万/千万美元级流程，但未公开额度、审批、日志、模型版本、回滚与事故记录 |
| 资产权利 vs 社区正当性 | S23 显示并购和投票权可以产生技术控制，却同时触发社区分叉 |
| 人物影响 vs 法律控制 | S20 将顾问、独立承包与公司代理/合伙明确分开 |
| 政治接近 vs 关系可逆 | S32/S33 显示以资本换取政治可见度，S36 显示同一关系在 18 个月内变为双向诉讼 |

| 预先策划 vs 反馈追加 | S43 称香蕉竞价有预算，但“吃掉”是在看到媒体反馈后决定；不应把传播成功全部倒写成全知计划 |
| 制造热度 vs 承受热度 | S19 表明高曝光可以从资产转化为监管、声誉和执行负担 |

## 使用方式

当前哪一端占优，以及什么触发转换，决定行为预测。“虚伪”或“天才”这类单词只表达态度，不能解释机制。

## 四类矛盾来源

**角色冲突。** 外交代表强调规则、可预测性和多边协作；创业者强调速度、突破与规则形成期；收藏者强调互联网共识；危机当事人强调事实与名誉。不同角色使用不同语域，不构成同一场景中的自我否定。

**时间演化。** S06 的早期个人意志与 S08 的成熟角色适配相隔多年。后期表达不是删除早期模式，而是在法律、团队与规模约束增加后加入新的决策条件。

**权利层级。** 个人影响、品牌可见度、顾问合同、持股、投票权、董事席位和法律控制属于不同层。S20/S25/S26 要求把这些层级并列，而不是选一个最有戏剧性的标签。

**传播与执行。** 高确定性语言提高传播效率，但技术、市场和法律结果仍有不确定性。合格分析把确定的动作、目标、当期数据和未来承诺分别表述。

## 转换触发器

| 从哪一端 | 转向哪一端 | 典型触发 |
|---|---|---|
| 高调放大 | 低调修复 | 事实错误、合作方异议、产品承载不足、S19 式过载 |
| 个人发言 | 机构发言 | 法律、安全、储备、制裁与用户损失 |
| 快速进入 | 等待/退出 | 不可逆责任不清、需求无法验证、牌照或制裁风险 |
| 关系信任 | 合同防护 | 金额扩大、治理权重要、冻结或退出风险上升 |
| AI 自动化 | 人工复核 | 高金额、外部发布、法律判断、模型冲突与异常日志 |

## 分析示例

面对“他既讲去中心化又保持个人影响”时，不直接判伪。先拆协议共识与治理规则、公司和金库权利、品牌分发、实际投票集中度，再说明个人影响在哪一层有效。面对“100% 听 AI”时，用 S41 的人类否决与律师路由限定：这是强调使用强度的公开表达，不是固定授权政策。

## 输出格式

`表面矛盾 → 两端证据 → 角色/时间/权利/传播来源 → 当前哪端占优 → 转换条件 → 不能推出什么`。结论使用明确条件句，不用模糊人格词。
