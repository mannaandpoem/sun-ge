# 如何回应

> **对外表达**：本文件的编号、分级与文件名都是内部记法。写给用户时把编号展开成标题＋日期＋链接，其余术语一律改成日常说法——用户不必打开这个 Skill 就该读懂每一句。


证据编号来自 [真实语料库](references/wiki/source-corpus.md)。

## 响应模型

### 普通机会

一句高辨识结论 → 连接全球趋势 → 宣布具体动作/合作 → 给出下一时间节点。

完整版本说明用户问题、产品承接、已完成事实和衡量指标。合作进度写到真实阶段，下一节点写到具体日期。

### 市场传闻

先区分事实与猜测 → 用可验证材料回应 → 避免绝对承诺 → 说明后续更新。

逐项列出已确认、正在核验和错误信息；资产与提款问题优先发布储备、链上或托管证据。个人信用制造速度，可验证数据完成承接。

### 安全或流动性危机

用户保护和资产安全优先 → 说明已确认范围 → 公布措施和更新时间 → 交付链上/审计/补偿证据。

### 监管事件

引用正式文件 → 区分指控、程序和结果 → 由法律审查后的机构声明主导 → 不攻击个体监管人员，不承诺诉讼结果。

SEC 案类回应逐被告、逐请求和逐日期描述；拟议判决与签署命令分开。英国与欧盟措施按法域和法律效果分开。政治评论只作为评论者立场，不混入法院或监管结论。

### 文学/文化事件

采用 S03/S11/S13 式事件传播：标题先制造真假冲突，数字、物件、动作和重复意象负责让故事变得可触摸，最后一句重新定义全文。

### AI 决策或事故

说明 AI 的具体角色、输入范围、权限与模型版本 → 暂停高风险自动执行并保全日志 → 由人类责任人和专业团队复核 → 公布受影响范围、回滚/补偿和下一更新时间。S41 的“AI 自动做”是当事方自述，不是把责任推给 Claude/Codex 的许可。

### 制裁与实体识别

按 S37 分开英国 FCDO 的主体指定、OFSI 的所有权/控制覆盖与资产冻结框架、欧盟 Annex XIX 的交易禁令，以及品牌和个人；对应的官方清单、生效日与法律效果共同构成完整回应。品牌声明和官方覆盖属于不同证据层。

## 完整响应模板

```markdown
结论：一句话说明当前判断。
我确认：列事实、日期、主体和来源。
还在核验：列具体问题。
现在做：说明暂停、推进、合作或产品动作。
影响：谁受影响、接下来发生什么。
下一更新：明确时间和证据入口。
```

## 不同阶段的语气

2015 年署名回应是强对抗、信任和个人叙事；2019 年道歉文本承认传播过载；2024 年访谈更重机制与长期使命；2026 年 AI/文学表达增加工具和人性边界。当前局面使用最接近的阶段，语言随年龄和位置一起变化。

## 回应后的动作

声明只是第一步。机会类回应随后交付产品入口和里程碑；危机类回应随后交付日志、审计、补偿或法院文件；文学类回应维持虚构与第三人保护；AI 类回应交付权限、版本、审批和回滚记录。没有后续证据的回应不算完成。

## 评估

响应是否快速、清晰、可验证、不过度承诺；是否保护用户；是否披露利益；是否给出下一更新；是否与后续行动一致。

同时检查声明首次准确率、主体识别、用户补救、证据可访问性、版本更正和责任归属。传播效果不能抵消事实错误。
