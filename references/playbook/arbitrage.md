# 套利

这里的“套利”指信息、分发、制度、品牌和资源之间的错配。

证据编号来自 [真实语料库](references/wiki/source-corpus.md)。

## 可研究的错配

- **注意力错配**：重要产品没有叙事，或热门叙事没有承接。
- **分发错配**：成熟用户入口尚未连接新协议或资产。
- **品牌错配**：传统圈层符号尚未被新技术语境解释。
- **地域错配**：不同市场的需求、基础设施和合规成熟度不同。
- **资产错配**：品牌、协议、用户或数据的市场定价与协同价值不同。
- **速度错配**：大机构反应慢，小团队可快速试验并保留退出权。

## 评估

错配为何存在；谁会修复；优势能持续多久；执行成本；合规要求；失败时最大损失；是否伤害用户或市场完整性。

## 真实语料中的三种套利观

- **规则套利（S02/S06）**：在资源尚未分完时进入，不是在规则成熟后内卷。
- **分发套利（S09）**：把技术、名人文化符号、机构合作和媒体内容合并，获得跨圈层传播。
- **互联网价值套利（S11/S13）**：购买已具备模因传播力的文化资产，再用公开行为提高自己与资产的共同可见度。
- **机器结算错配（S42）**：AI Agent 有调用和执行需求，但账户、身份、支付与合规责任尚未成熟。它是产品方提出的机会假说，需用真实调用与收入验证。

S12/S36 的政治/商业连接显示制度套利最容易越过伦理、合同和利益冲突边界；S37 又说明跨辖区差异可转化为制裁传导，而不是安全退出。此类分析必须同时写监管、公共利益和反腐败风险。

## 错配如何转化为优势

套利不是发现差价就结束，而是把暂时错配变成持久能力。注意力错配转成自有分发；地域错配转成牌照和本地产品；资产错配转成合同权利、现金流或网络效应；速度错配转成数据、标准或用户习惯。没有留存机制的错配，只产生一次性收益。

## 逐项评估协议

1. **定义两端：** 哪两个市场、圈层、制度或产品之间存在差异。
2. **确认原因：** 差异来自信息慢、进入成本、监管限制、技术缺口还是虚假需求。
3. **取得权利：** 需要股权、代币、合同、牌照、渠道还是内容授权。
4. **设计承接：** 用户和合作方如何从错配进入产品并长期留下。
5. **计算消失速度：** 竞争者、监管或标准会在何时修复差异。
6. **核算外部性：** 用户、市场完整性、公共利益和合作方承担什么成本。

## 案例拆解

- **《Comedian》：** 传统艺术市场拥有作品权利，加密与互联网文化拥有传播解释。购买证书取得合法参与位置，公开行动连接两个圈层。收益包括资产历史和个人可见度，风险是高成本与争议。
- **BitTorrent/TRON：** 成熟分发网络与新公链生态存在用户入口错配。分析必须回到收购权利、产品整合和后续使用，不能只用“用户数协同”描述。
- **AI Agent 结算：** 模型调用需求已经存在，Agent 身份、预算和结算责任仍不成熟。B.AI 的机会在于连接这些环节；护城河必须由真实调用、收入、安全和切换成本证明。
- **跨辖区运营：** 不同法域提供市场机会，也形成制裁、牌照和实体穿透风险。S37 证明地域差异不是天然保护层。

## 成功标准

优势在错配缩小后仍能保留用户、数据、标准、品牌、牌照或网络效应；收入可被审计；用户可以理解并退出；关联与利益得到披露。只靠信息不对称持续存在的模式，不属于可持续打法。
