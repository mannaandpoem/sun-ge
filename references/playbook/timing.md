# 时机

证据编号来自 [真实语料库](references/wiki/source-corpus.md)。

## 时间窗口

- 市场周期切换：牛市扩张、熊市整合、危机后信任重建。
- 政策窗口：监管澄清、执法变化、地域性准入。
- 技术窗口：网络升级、成本下降、新标准或新分发渠道。
- 注意力窗口：大众事件、行业争论、竞品失误或跨界热点。
- 资本窗口：资产估值、融资条件、被收购方压力或上市市场需求。

## 决策问题

为何现在而非六个月后；窗口会持续多久；先发优势是否真实；提前进入的合规和执行成本；若热点反转如何退出。

## 反模式

把追热点当成策略本身；在事实未清时过早绑定声誉；用市场上涨证明时机判断；忽略团队承载力和后续产品交付。

## 原生模型：规则制定期

S02/S06 明确提出：财富和机会更容易集中在规则正在制定、资源尚未分配完的领域；信息敏感度和早期进入产生非线性回报。判断时依次经过：

1. 规则是真的未定，还是需求根本不存在？
2. 早期进入能获得用户、数据、标准、代币、股权还是治理权？
3. 规则成熟后，优势能否留存？
4. 最坏情况是试错成本，还是不可逆监管/安全损失？

S04 把这一模型更新到 AI、机器人、无人机、太空和区块链；说明赛道名称会变，选择逻辑相对稳定。

S42 把 AI Agent 支付描述为规则与基础设施尚未成熟的窗口；验证时必须先问 Agent 是否已有真实付费需求、权限责任是否可落地。S43 则提供“第二时钟”：取得资产后读取媒体反馈，再决定是否追加传播动作。时机不只发生在入场前，也发生在成交后的反馈窗口。

## 两阶段时钟

**进入时钟**决定何时取得资产、技术、用户或标准位置。判断依据包括规则成熟度、竞争密度、用户痛点、基础设施成本和监管路径。早进入的价值是参与定义接口与资源分配，不是单纯买得更便宜。

**放大时钟**决定何时公布、追加资本、制造事件或跨圈传播。S43 展示清晰顺序：先取得作品，再读取全球媒体反馈，随后决定公开食用。该顺序减少了在反馈出现前过度承诺的成本。

## 阶段门

| 阶段 | 必须回答 | 通过后动作 |
|---|---|---|
| 观察 | 用户是否真实付费或持续使用 | 小额研究与原型 |
| 试验 | 技术、合规和分发能否同时成立 | 限额试点 |
| 取得入口 | 资产、合同或标准位置是否明确 | 签约、投资或收购 |
| 放大 | 数据是否支持更大曝光和资本 | 公告、合作、事件化 |
| 固化 | 优势能否变成网络效应或制度位置 | 长期产品、治理和品牌建设 |
| 退出 | 假设被什么事实推翻 | 停止投入、转让或降级 |

## 判断“太早”与“太晚”

需求不存在、关键依赖尚不可用、责任主体无法确定、单次错误会造成不可逆用户损失时，属于太早。规则已经稳定、入口被少数平台锁定、获取成本超过可形成的网络优势时，属于太晚。最佳窗口位于真实需求已出现、基础设施刚能工作、标准和分发仍可争取的阶段。

## 案例校准

S02/S06 支持早期规则参与；S19 说明传播节奏超过事实与组织承载会反噬；S34 说明事件权利可以多年后兑现；S36 说明关系和合同条件会在时间中变化，曾经的联盟不能当作永久状态。时机分析必须同时看进入、执行、放大和退出，不能只看买入日期。

## 输出格式

写清窗口类型、剩余时间、先发优势来源、立即行动成本、等待获得的信息、下一阶段门槛、停止条件。若等待能显著降低不可逆风险而不会失去入口，等待就是主动策略，不是缺乏判断。
