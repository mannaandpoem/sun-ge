# 注意力

证据编号来自 [真实语料库](references/wiki/source-corpus.md)。

## 可观察打法

1. 选择大众能瞬间理解的高辨识事件，而非只讲抽象协议。
2. 让事件同时跨越加密、财经、娱乐、艺术或国际事务多个版面。
3. 用个人账号缩短项目到媒体和用户的分发链路。
4. 通过连续节点维持议程存在感，而非依赖一次发布。
5. 将争议产生的认知重新导向产品或立场说明。

## 真实案例链

- **巴菲特午餐（S05/S19）**：用传统投资权威为加密议题创建全球新闻钩子；会面不等于背书。S19 说明该事件也曾进入本人所称的“过度营销”状态，必须同时教上限与回撤。
- **Hans Zimmer + Bruce Lee（S09）**：用文化符号给技术品牌增加记忆点。
- **《Comedian》购买与吃掉（S11/S13）**：先购买已有互联网势能的作品，再通过履约把自己写进作品历史。
- **拍卖后的反馈回路（S43）**：本人称拍卖前设置预算，成交后看到全球媒体反馈才决定公开食用。该案例明确呈现“先取得事件权利，再根据反馈追加动作”，而非全程预谋。
- **诉讼＋长文双通道（S03/S147/S148）**：2026-08-27 同一天，代理律师发布已立案的诉讼说明，他本人在 X 发出用真实姓名和精确金额写成的第一人称长文。法律通道走程序，叙事通道抢解释权，虚构声明充当传播外壳。这是把注意力打法用进私人纠纷的完整样本，也是风险最高的一次——对方当事人公开否认，法院尚无实体认定。可研究动作结构，不可据此陈述事实。**结果要一并记住：传播极成功，框架争夺失败**，主流舆论倒向嘲讽而非同情，详见 [景甜案](references/wiki/jingtian-case.md) 第七节。

这些案例共同表明：最强注意力动作往往不是“投广告”，而是购买或创造一个自己可以成为角色的事件。S34 的太空飞行还显示，事件权利可跨多年兑现。

但这只是高曝光样本的观察结论，存在幸存者偏差。预测时必须同时生成“不追、低调试验、交给机构”选项，并用 S19 作过载反例。

## 完整机制

`高辨识事件 → 一句话新闻钩子 → 跨圈层转载 → 个人成为事件角色 → 项目或资产获得搜索入口 → 产品承接 → 留存与收入`

前四步属于传播，后三步属于商业。孙宇晨案例的鲜明之处，是他经常通过竞拍、会面、持仓、旅行或写作取得“事件角色”，而不是只购买广告位。角色使媒体标题天然包含人物和动作，也让事件可在多年后继续被调用。

## 事件设计清单

1. **新闻句：** 陌生读者能否用一句话准确复述？
2. **参与权：** 行动者是否真的拥有资产、席位、合同或公开发言资格？
3. **跨圈层：** 除加密媒体外，财经、艺术、科技或大众媒体为何会报道？
4. **产品桥：** 事件结束后，用户进入哪个钱包、协议、产品或资料页？
5. **证据包：** 金额、日期、合同、交易哈希、现场记录与利益关系是否可核验？
6. **停止线：** 负面情绪、事实错误、合作方异议或产品承载不足达到什么阈值时降温？

## 三类打法

- **购买现成势能：** 巴菲特午餐、《Comedian》与太空席位都先取得稀缺事件权利，再组织传播。优势是新闻价值已存在，风险是高成本与背书误读。
- **创造新文本：** S03 依靠标题、真实姓名、精确数字与真假边界制造传播。优势是分发速度快，风险是真实第三人的名誉与隐私被卷入——本案对方已把它定性为“以艺人声誉为要挟的碰瓷行为”（S148），说明这条路的反弹会落到法律和声誉两侧。
- **绑定产品里程碑：** S05/S09 把合作、网络和文化符号串入生态时间线。优势是事件有产品承接，风险是公告领先于交付。

## 过载识别

当媒体只讨论人物而不再讨论产品、合作方开始澄清“并非背书”、后续声明反复修正事实、团队无法兑现流量、负面声誉成本超过新增用户价值时，注意力已从资产变成负债。S19 要求此时主动降频、纠错并把发言权交给机构或专业负责人。

## 衡量

曝光量只是顶层指标。继续测量品牌搜索、产品访问、激活、真实交易需求、留存、开发者活动、合作转化和负面声誉成本。

评估报告应把指标分成四层：媒体覆盖和搜索属于认知；访问和注册属于兴趣；交易、开发和结算属于使用；留存、收入和网络效应属于价值。只有最后两层增长，才能证明事件完成商业承接。
