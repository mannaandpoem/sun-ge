# 关系网络

证据编号来自 [真实语料库](references/wiki/source-corpus.md)。

## 网络的功能

进入新圈层、获得信息、建立分发、降低交易摩擦、提高可信度、创造谈判选项和危机协调能力。

## 可观察打法

- 通过高辨识事件获得与传统金融、艺术、科技或公共部门的接触面。
- 让合作本身成为媒体事件，从而反向提高合作价值。
- 在多地域和多行业维持弱连接，保留未来选项。
- 把个人关系、项目合作和机构合作分层运营。

## 核验

区分会面、合影、发言、顾问、合同、投资、董事权和控制权。只有后四类通常能证明更强关系；仍需看期限和法律文件。

## 有来源的网络形态

- S05：巴菲特、外交、艺术、太空、HTX 顾问等官方选择的身份节点。
- S09：艺术家/作曲家、技术基础设施公司与公链治理节点被整合到品牌叙事。
- S12：政治家族项目投资显示关系网络会直接与监管和公共利益问题相遇。
- S01：私人信任被媒体公开的冲突说明网络不仅是资源，也是泄露和背叛风险。
- S32/S33 到 S36：投资、顾问/活动接近和后来的互诉构成“关系可逆”样本；网络入口不是永久联盟。
- S37：品牌网络还会传导制裁与合规风险；法律主体隔离不能自动隔离交易所品牌。

真正的网络能力不是“认识谁”，而是把一次关系转化为长期入口，同时处理背书误读、利益冲突、退出权与关系反转。

## 关系强度阶梯

| 层级 | 可验证凭证 | 能支持的结论 |
|---|---|---|
| 同场/合影 | 活动议程、照片、视频 | 双方曾在同一场合，不证明合作 |
| 公开交流 | 完整访谈、会面记录、双方声明 | 存在交流，不证明认可或承诺 |
| 合作/顾问 | 合同、任命公告、期限与职责 | 在约定范围内合作，不证明控制 |
| 投资/持仓 | 备案、链上记录、交易文件 | 存在经济利益，不证明治理权 |
| 董事/治理 | 公司备案、投票权、章程 | 具有明确治理能力，仍需看比例与限制 |
| 控制 | 受益所有权、投票安排、金库和一致行动证据 | 可依法描述控制范围，不外推到关联生态 |

S20/S25 是关系分级的关键材料：孙宇晨与 TRON Inc. 的顾问、持股、亲属和生态联系均可确认，但备案同时给出独立承包、投票权和正式控制人的边界。任何关系图都必须把软影响与法律控制分层。

## 网络转化路径

一次会面只有在后续形成明确合作、共同产品、分发入口、标准参与或长期信息渠道时，才转成网络资产。转化流程是：建立接触 → 明确双方交换价值 → 签署范围与披露 → 交付一个小结果 → 复盘利益冲突 → 再扩大关系。

巴菲特午餐展示高辨识接触的传播价值，也展示背书误读与过度营销风险；WLFI 从投资和活动接近转为互诉，展示关系可逆；HTX/Huobi 的制裁文件展示品牌网络会传导法律和声誉风险。

## 公共部门与政治关系

公共部门关系必须提高证据门槛。会议、捐赠、投资、头衔和政策结果分别记录，不得暗示因果交换。执行反贿赂、礼品、游说、政治捐款、利益冲突和制裁审查；涉及监管结果时，以正式决定和程序文件为准。

## 退出设计

合同应写明期限、公告权、姓名与商标使用、数据和知识产权、解约、资产解锁、治理权、争议解决与制裁条款。关系结束时同步更新官网、媒体资料和权限，避免历史称谓继续被当作现状。

## 回答模板

`关系双方 → 关系类型 → 起止日期 → 一手凭证 → 交换价值 → 法律权利 → 利益冲突 → 当前状态 → 不能推出什么`。这套结构同时适用于人物关系、机构合作和政治接近度分析。
