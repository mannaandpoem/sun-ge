# 资本

证据编号来自 [真实语料库](references/wiki/source-corpus.md)。

## 资本不只是一笔钱

将资金、代币、股权、品牌、用户入口、流动性、治理权、牌照和关系视为不同资本。交易的意义常在组合，而非单一财务回报。

## 资本配置问题

1. 购买的是现金流、用户、叙事还是选择权？
2. 资产与生态是否存在可验证协同？
3. 对价和风险由谁承担？
4. 是否有关联交易、托管或估值冲突？
5. 退出、赎回和流动性压力由谁吸收？

## 评价框架

比较资本成本、整合成本、曝光价值、产品转化、治理影响、合规成本、下行保护和五年机会成本。

## 反模式

把大额支出等同于实力；把资产升值全归因于操盘；忽略锁定、托管、关联方和市场冲击；只展示名义价值不展示风险暴露。

## 资本作为叙事媒介

S11/S13 中，620 万美元购买的不只是可替换香蕉，而是证书、作品历史、互联网注意力与参与权。S12 中，大额政治关联投资同时包含金融、品牌、制度和法律期权，媒体也提出严重利益冲突解释。S03 反向展示：当支付能力不再构成约束，真正决定关系的是是否存在边界和拒绝。作者称文中自己的想法属实（S41），但其中的金额与对方行为未获独立证实。

S19/S23 是两个必读反例：资本可买到公共议程或投票能力，但不自动买到可控传播、监管容忍或社区正当性。S20 则显示品牌和顾问关系必须回到合同权利，不能用“影响力”代替法律控制。

S32/S33/S36 构成第三个完整反例：资本和持仓可以买到顾问称谓、活动席位与政治可见度，但后来仍出现代币冻结、治理权争议和互诉。S43 则提供交易纪律线索：团队曾设置竞价上限，传播动作是在成交后按反馈追加；预算纪律与事后叙事要分开分析。

分析大额动作时强制拆成：`资产权利｜现金流｜流动性｜公共事件价值｜关系期权｜法律/声誉尾部风险`。

## 资本动作的四种目的

**建设型资本**购买技术、人才、牌照和基础设施，回报来自长期产品能力。**入口型资本**购买用户、渠道、流动性或治理位置，回报来自网络协同。**事件型资本**购买稀缺席位、作品或持仓资格，回报包含传播与身份。**关系型资本**建立合作和制度接近度，回报取决于合同权利与关系持续性。

同一交易可以同时属于多类。S31 是资产与事件资本；S32/S33 是资产、关系和活动资格；S20/S25 涉及上市公司、顾问与控制权，必须用备案拆开。分类的目的，是防止把所有回报都写成“战略价值”。

## 交易前检查

| 项目 | 核心问题 |
|---|---|
| 权利 | 买到股权、代币、治理、内容授权还是仅有顾问称谓 |
| 对价 | 现金、稳定币、股份、锁仓与附带承诺分别多少 |
| 控制 | 投票权、董事席位、否决权、金库与私钥由谁掌握 |
| 现金流 | 收入来自用户、资产价格、费用还是关联方 |
| 流动性 | 解锁、赎回、转让、冻结和市场冲击如何处理 |
| 关系 | 合作期限、公告权、背书限制和利益冲突如何写入合同 |
| 下行 | 诉讼、制裁、技术失败与声誉成本由谁承担 |

## 交易后管理

资本落地后立即建立权利台账、关联方清单、托管/密钥责任、信息披露日历、整合指标和退出触发条件。S36 说明公开联盟无法替代冻结、治理和争议解决条款；S23 说明技术控制也无法替代社区正当性。

事件型资产还需要单独的传播预算和停止线。S43 中竞价范围与成交后的传播追加是两个决策，不能把后续曝光价值倒推成无限竞价理由。应先确定资产本身和事件期权的最高支付意愿，再按真实反馈追加。

## 回报归因

价格上涨、媒体曝光和网络增长必须分别归因。市场周期、行业 Beta、项目交付、个人事件和关联方行为都会影响结果。没有反事实比较时，不把全部上涨归于单次资本动作，也不把一次下跌证明为战略失败。

## 输出模板

`交易事实 → 取得的法律权利 → 资本类型 → 协同机制 → 价值捕获 → 关系与治理边界 → 下行情景 → 退出条件 → 仍需取得的文件`。每一项使用明确名词和数字，避免“生态赋能”“深度协同”这类不可核验表达。
