# 谈判

本文件从公开交易和传播行为提取谈判模式。

## 公开记录

公开资料没有内部谈判逐字稿，因此本文件不虚构具体话术。它从已公开的交易结构、预算、自述与事后结果中提取可验证做法。S20 证明顾问协议的公开条款；S43 证明一次拍卖设有预算范围；S36 证明投资关系仍需冻结、治理和争议条款；S19/S23 用于检查公告、营销和资产权利如何在交易后反噬。

## 候选模式

- 扩大议题：把价格谈判转化为品牌、分发、生态和长期关系的组合交易。
- 创造替代：跨市场、跨资产和跨合作方保留 BATNA。
- 使用速度：快速承诺换取先发和议程控制，但保留尽调门槛。
- 制造公共价值：让交易具备传播性，使对手也能获得曝光或定位收益。
- 分阶段：先合作或顾问，再以交付结果决定是否扩大资本和治理关系。
- 预设价格边界：S43 中本人称团队为香蕉拍卖设置估值/竞价范围；这是单一公开自述，可作为“有预算上限”的实例，不能推广成稳定谈判术。
- 权利必须写进合同：S36 的冻结与互诉说明，投资金额和公开亲近不能替代解锁、转让、治理、争议解决与退出条款。

## 检查表

对方真正稀缺的是什么；哪些条件可公开、哪些必须保密；谁承担监管和声誉风险；解锁/治理/冻结与退出条款；关联方；公告是否先于正式文件；失败后如何降级。

## 谈判对象拆解

价格只是表面变量。对手还在交换时间、分发、信誉、治理、排他性、流动性、数据和退出权。谈判前为每项标出“必须取得、可以交换、绝不接受”，避免用大额价格掩盖权利空缺。

在艺术与事件交易中，稀缺物是证书、席位和进入历史的资格；在协议/公司交易中，稀缺物是用户、代码、牌照、股权、投票权与金库权限；在关系交易中，稀缺物是公开关联、活动入口和长期合作。不同对象必须使用不同尽调清单。

## 分阶段结构

1. **探索：** 交换有限信息，确认利益与合规冲突。
2. **试点：** 小范围、短周期、明确指标，不预先承诺全面合作。
3. **扩大：** 达标后增加资本、地区、产品或治理权限。
4. **固化：** 把品牌使用、数据、知识产权、审计和续约写入合同。
5. **退出：** 触发冻结、违约、制裁、声誉或产品失败条款时终止。

## BATNA 与公开传播

跨市场和跨资产布局可以提高替代方案，但替代方案必须真实存在，不能虚构其他报价。公告只在核心文件签署、主体和条款核验后发布；传播稿不得扩大合同范围，也不得把接触写成背书。

## 从 S36 得出的合同清单

代币或股权交易必须覆盖解锁、转让、冻结、治理投票、信息权、追加购买、价格/做空限制、关联账户、争议解决和紧急救济。公开亲近和投资规模不能代替这些权利。谈判成功的标准是权利、责任和退出清楚，不是发布会声量。

## 复盘标准

成交后比较实际取得权利与原目标、对价与机会成本、公告与合同差异、合作交付、争议和退出准备。若传播价值高但权利薄弱，应把结果归类为事件合作，而不是战略控制。

## 输出模板

`谈判目标 → 对方稀缺资源 → 我方可交换资源 → 必须取得权利 → 可让步项 → BATNA → 分阶段安排 → 公告条件 → 风险分配 → 退出与争议解决`。

判断谈判时，优先考虑能叠加资产、分发、关系和事件价值的交易结构；同时用 S19、S23、S36 检查传播过载、社区正当性和关系反转。合同把价格之外的权利、责任和退出固定下来。
