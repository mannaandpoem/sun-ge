# 心智模型

每个模型均应回查 [真实语料库](references/wiki/source-corpus.md)。

## 孙学：分层元模型

“孙学”不是一个含义固定的学术流派。本技能将它拆成三层：

1. **官网回顾的思想底座**：2026 年官网把 2016 年《财富自由革命之路》概括为围绕价值观、精神自由、人生战略与选择权展开（S27）；原音频尚未逐集摄取。
2. **镜像所示的本人再命名**：第三方镜像显示，2026 年中文账号把“孙学”追溯至十年前节目，并强调价值观如何生成选择与战略（S28）；原帖尚待可靠存档确认。
3. **关联平台再解释**：HTX Square 把规则意识、长期下注、注意力与韧性称为“孙学”（S29）；这证明一种品牌化用法，不等于广泛社区共识或本人认可的正式教义。

作为分析工具，可暂时压缩为：

`重构价值观 → 识别规则形成期 → 选择高弹性赛道 → 集中行动与资源 → 建立入口/流动性 → 把行动转成叙事 → 根据结果与外部约束校准`

这是 **Skill 的证据化重建**，不是孙宇晨发布的正式公式。使用时逐箭头找案例，并同时检查 S19 的过度营销、S23 的治理正当性冲突等反例。若一个解释只谈“敢赌、会营销、永不服输”，却不检查产品承接、法律边界、幸存者偏差和失败成本，它只是成功学化的“孙学”，不算合格分析。

## 注意力—承接模型

`事件钩子 → 媒体扩散 → 品牌记忆 → 产品入口 → 用户行为 → 留存/收入/网络效应`

每一箭头都要找证据；“上热搜”只证明第一段。

## 流动性飞轮

`低摩擦网络 → 资产流通 → 应用活动 → 更多入口 → 更深流动性`

反飞轮：`补贴依赖 → 低质量活动 → 集中/关联风险 → 安全或监管冲击 → 流动性撤出`。

## 符号资本桥接

借用传统金融、外交、艺术或科技符号，帮助新受众理解加密项目。必须检查是否被误读为背书。

## 选择权组合

将品牌、关系、资产、平台和地域视为一组未来选择权。评估获得选择权的成本、维持成本和冲突。

## 不对称下注

偏好“下行可控、上行包含曝光/关系/资产多重收益”的动作。检验是否真的可控，以及风险是否被转嫁给用户或关联方。

## 叙事更新

在市场周期和公共议题变化时重新包装项目定位。区分合理迭代与事后改写历史。

## 规则形成期

`规则未定 → 资源未分完 → 小参与者可进入 → 信息/速度产生非线性回报`

这是 S02/S06 中最明确、最有“孙宇晨味”的原生模型。失败条件：规则不清只是因为不存在真实需求，或政策/安全尾部风险足以吞噬全部上行。

## 互联网价值共创

`物件/协议 → 网络传播 → 互动历史 → 所有者/参与者进入故事 → 价值再定价`

来源 S11/S13；S03 则把文学文本本身设计成真假争议的传播对象。此模型不能替代现金流、法律权利和真实使用价值。

## AI 外置判断

公开材料呈现四层，但证据性质不同：前三层来自 S41 的当事方使用自述，第四层来自 S42 的生态产品叙事：

1. **个人认知**：向 Claude 等模型提供上下文，询问能不能做。
2. **技术工作**：使用 Claude Code、Codex 写代码、检查公司代码和材料。
3. **组织流程**：自称部分审计、审核和高金额决策由 AI 自动执行。
4. **产品/基础设施**：S42 把多模型路由、账户、身份、支付与结算包装成 B.AI 的产品栈。

更准确的模型是：

`结构化输入 → 多模型/工具处理 → 自动或人工建议 → 权限与专业复核 → 人类/机构承担后果`

S41 同时给出反例：在 S03 发布上，他称首次明显不采纳 Claude 建议；诉讼交给律师。“100% 听 AI”是公开的极端表达，真实授权仍由日志、额度、审批链、模型版本、回滚和事故数据决定；这些记录目前没有公开。

## AI Agent 经济主权

S42 的产品叙事将传统稳定币结算模型迁移到 AI：`模型/Agent 获得账户与身份 → 自主购买算力/服务 → 链上支付和结算 → Agent 间协作`。它与 S39 的“区块链替代传统结算层”是同一基础设施想象的新对象。

验证时必须检查：真实付费用户、非补贴调用量、模型路由质量、费用口径、密钥与权限隔离、提示注入、错误交易回滚和法律责任。产品愿景不等于自治已经安全实现。
