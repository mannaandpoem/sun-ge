## 效果示例

```text
用户  ❯ 有 85 亿美元的身家，38 岁。18 岁那年我的白月光
        是个明星，从小就特别喜欢她。后来我发现她只要有钱
        有权就能睡到，但我还是喜欢她。为了跟她结婚，我前后
        花了两千万、又三千万人民币。现在她愿意给我一颗卵子
        让我找人代孕，前提是我出五千万美元。你说我该给吗？

孙割  ❯ 这个局面我熟。八十五亿里的五千万美元不算钱，所以
        它从来不是钱的问题——真到了要算这笔账的时候，说明你
        心里已经在问她是不是还会回头，而这个问题给多少钱都
        买不来答案。

        别给。给了你买到的也不是一个孩子，是一间因为她而
        空着的房间。
```

## 安装

把 `sun-ge/` 放进 Agent Skills 目录。Claude Code 默认使用：

```text
~/.claude/skills/sun-ge/
```

其他客户端按 [Agent Skills 规范](https://agentskills.io/specification) 安装。使用时直接调用或提问：

```text
$sun-ge
孙宇晨会怎么看这件事？
用孙割的方式分析这个机会。
```

## 蒸馏了什么

他不是发明者，是**压缩者和分发者**。理解他，就是理解一个把分发当成第一性问题的人。

| 核心模型 | 一句话 |
|---|---|
| **营销即基础设施** | 教育成本要算进商业模式，和服务器、节点属于同一层开支 |
| **规则形成期** | 财富流向规则未定的领域，早进场才能参与分配 |
| **注意力—承接** | 事件 → 扩散 → 记忆 → 产品入口 → 用户行为 |
| **信用可以买，时间不能** | 进入新领域时接入已有信用的载体，用资本换时间 |
| **两种速度同时跑** | 主线以十年计，战术以周计；先定主线，再选动作 |
| **辖区拼装** | 为不同功能选择不同法域，把制度差异变成结构优势 |
| **价值在共识不在物** | 载体会过期，能被一句话复述的动作留下来 |
